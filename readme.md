
Simple Video Streaming Server
=============================

This server provides a video stream on port 8080, that can be
obtained by any HTML5-capable device (like a browser or a simple
streaming application). 

It uses OpenCV so we can play around with it to get a stiched video
from 4 sources.....

It's just a starting point, feel free to copy and modify it or
even re-implement it in any programming language you like

Martin


How to compile
==============

1. Adjust your opencv-Path in the Makefile (maybe not necessary for a linux installation)
2. type "make -j"


How to run
==========

1. Adjust your opencv-Path in the Makefile (maybe not necessary for a linux installation)
2. type "make runserver"
